# 나의 지출 내역 v1.1

HTML, CSS, JavaScript와 localStorage로 동작하는 개인 지출 관리 앱입니다. 외부 서비스나 계정 없이 사용합니다.

## 실행 및 테스트

Node.js 24와 Python 3에서 다음 명령을 실행합니다. 앱 실행에는 Python만 필요하며 빌드가 필요하지 않습니다. 자동 브라우저 테스트 의존성은 `npm ci`로 설치합니다.

```sh
npm start
npm test
```

브라우저에서 개발 서버의 8000 포트를 엽니다. JavaScript 모듈을 사용하므로 HTML 파일을 직접 열지 말고 HTTP 서버를 사용하세요.

## 기능

- 날짜, 내용, 정수 원화 금액, 결제수단으로 지출 등록·수정·삭제
- 선택한 월의 전체 합계와 삼성카드·KB카드·수원페이·현금·계좌이체·기타별 합계
- 기존 신용카드·체크카드 기록과 월간 합계를 별도 표시하며, 수정 시 새 결제수단으로 변경 가능
- 기존 localStorage 키와 버전 1 JSON 백업 형식을 유지하며 자동 데이터 변환 없음
- 같은 브라우저와 출처에서 새로고침 후에도 내역 유지
- 버전 1 JSON 백업 다운로드와 복원. 복원은 전체 파일 검증과 사용자 확인 후 현재 목록 전체를 교체합니다. 빈 목록 복원도 전체 삭제에 해당합니다.
- 잘못된 날짜·금액·중복 ID·백업 버전 거부, 5MB 복원 제한
- 저장 실패 시 기존 화면 데이터를 유지하고 오류 안내. 저장 데이터가 손상되면 덮어쓰기를 차단하며 정상 백업 복원으로 복구 가능

브라우저 저장소 삭제, 시크릿 창 종료, 다른 기기·브라우저·출처로 이동할 때 데이터가 유지되지 않을 수 있습니다. 정기적으로 JSON 백업을 보관하세요. 백업에는 지출 내용이 평문으로 포함됩니다.

## v1.1 회귀 테스트

```sh
npm ci
npm test
npx playwright install chromium
npm run test:e2e
```

시스템 Chromium을 사용하는 환경에서는 다운로드 대신
`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e`를 실행할 수 있습니다.
브라우저 테스트가 개발 서버를 자동 실행하며 기존 데이터 읽기, 6개 수단 등록, 월간 합계, 수정·삭제, JSON 백업·복원을 검증합니다.

GitHub Pages는 기존 정적 파일 배포 방식을 유지합니다. 저장소 루트의 `index.html`, `app.js`, `model.js`, `styles.css`를 그대로 제공하며 Node.js와 테스트 도구는 앱 실행에 필요하지 않습니다.
